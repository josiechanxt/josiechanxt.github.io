STASH: Physical-to-Digital artefacts for design inspiration.

Project 1 • 2026

STASH is a web app I built to solve physical clutter by digitising physical design artifacts. It instantly captures packaging, cup sleeves, and postcards, converting them into clean, background-removed digital collectibles organised on the go for design inspiration.

👉 Try it out: josiechanxt.github.io/Stash.

[ METHOD ]

Figma MCP + Codex pipeline for a functional web app

I designed the UI in Figma and used Figma MCP, Codex, and React.js to create a design-to-code pipeline. By feeding canvas data directly into Codex, the AI generated frontend code straight from my visual layouts, allowing me to ship a functional web app in just three days.
